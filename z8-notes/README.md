# Z8 notes

The working memory of the Z8 G4 lab host (`berlin-3eie`), mirrored from
`~/moe-infinity/` on that machine. It lives here so the project's memory
travels with the repository instead of existing only on one host.

| File | Answers |
|---|---|
| [`../CLAUDE.md`](../CLAUDE.md) | *What is true now?* Standing state, rewritten in place. |
| [`todolist.md`](todolist.md) | *What do we owe?* A queue, plus the gate rule: close one before opening another. |
| [`assets.md`](assets.md) | *What is this machine?* Measured hardware inventory and what each part implies. |
| [`logbook/logbook_sNNN.md`](logbook/) | *What happened on that day?* One file per UTC day, append-only. |
| [`logbook/logbook_issue123.md`](logbook/logbook_issue123.md) | *Where does that investigation stand?* Per problem, across days. |
| [`status.sh`](status.sh) | Run on the Z8 for a fast snapshot after a session is interrupted. |
| [`archive/`](archive/) | Retired scripts, kept with a note explaining why not to run them. |

**Reading order:** `CLAUDE.md`, then `todolist.md`, then the highest-numbered
logbook, then `logbook_issue123.md` if you are picking up the OLMoE work.

These are notes about one specific machine, not project documentation. Nothing
here should be read as applying to MoE-Infinity generally.
